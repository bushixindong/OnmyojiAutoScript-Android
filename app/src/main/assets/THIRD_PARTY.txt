## 嵌入运行时与 Python 依赖

Python 3.10（PSF）、Chaquopy 17.2.0（MIT）、Pydantic 2.10.0 / Pydantic Core 2.27.0（MIT）用于原任务运行和配置验证。Core 是使用 NDK r27d/Rust 1.85.1 为 Android ARM64/x86_64 自编译的原生扩展，编译和打包脚本随工程提供。

NumPy、SciPy、Pandas、Pillow、OpenCV Python、Shapely/GEOS、requests、cryptography、pycryptodome、lxml、FastAPI、Paho、Onepush、ppocr-onnx 及其传递依赖保留各自协议。实际安装版本与复制的原始 LICENSE/COPYING/NOTICE 列表打包于 app/src/main/assets/python-licenses/index.json，原文在相邻目录。GEOS/libgfortran 等组件的协议与运行时例外以这些原文为准。

参考网址：[Chaquopy](https://github.com/chaquo/chaquopy)、[Python](https://www.python.org/psf/license/)、[Pydantic Core](https://github.com/pydantic/pydantic-core)、[Shapely](https://github.com/shapely/shapely)。

百鬼夜行跟踪库和模型按用户要求暂缓，不随本版运行时接入。

## 0.4.3 实时预览

MaaMeow 同一固定提交的 BackgroundTaskView.kt、BackgroundTaskViewModel.kt、bridge_preview.cpp 用于 Surface 生命周期、GPU 实时画面和虚拟屏触控的实现参考；本工程以 Java SurfaceTexture/EGL 双输出重写，未复制其 C++ 渲染代码。预览与识别共用虚拟屏输入，预览不经过图像编码。相关文件遵循本项目 AGPL-3.0-only。

## 0.5.0 原始帧通道与系统优化

MaaMeow 同一固定提交的 bridge_frame_buffer.cpp、VirtualDisplayManager.kt（CompanionDevice + VirtualDevice 分支）、PowerController / RemoteScreenPowerController.kt、GameAudioMuteController、GameFpsMonitor.kt 及多点触控预览模型用于 raw_frames.cpp、RawFrameStore.java、RawFrameReader.java、VirtualDeviceDisplay.java、ScreenPower.java、GameAudio.java、GameFpsMonitor.java 与 ManualTouchController.java 的实现参考；相关文件遵循本项目 AGPL-3.0-only。
